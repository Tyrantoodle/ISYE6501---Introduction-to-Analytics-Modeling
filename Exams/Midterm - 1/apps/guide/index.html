1. Foundations and terminology — Modules 1–2

Descriptive: what happened, what patterns exist, how factors relate. Predictive: what value/outcome is expected for new or future observations. Prescriptive: what action to take, given objectives and constraints. A forecast alone does not choose the best action; it can feed a decision model.

“Model” has three levels: the method family (regression), a specification (regression using size, weight, distance), and a fitted equation with numerical coefficients. Be explicit about which level a question concerns.

Rows are observations/data points. Columns are attributes/features; explanatory columns are also predictors/covariates. The response/outcome is the answer to estimate. Structured data fits a defined representation; free text is a lecture example of unstructured data requiring feature extraction.

Quantitative values measure magnitude. Categorical values identify groups; a ZIP code written as a number is still categorical. Binary variables have two categories and can often be encoded 0/1. Time series have temporal ordering, frequently at equal intervals; ordering matters even if storage looks like an ordinary table.

Supervised learning uses observed responses (classification and regression). Unsupervised learning uses features without known responses (clustering and PCA). Assigning a new observation to a learned cluster does not change the original clustering into supervised learning.

2. Classification, SVM, neighbors, and scaling — Module 2

Linear SVM

Let f(x) = b + Σⱼwⱼxⱼ. Classify using the sign of f(x). The separator is f(x)=0; margin boundaries are f(x)=±1.

  • Labels yᵢ = ±1 allow the single constraint yᵢf(xᵢ) ≥ 1.
  • Hard-margin optimization: minimize ||w||² subject to those constraints.
  • Margin width is 2/||w||. Smaller coefficient norm means larger margin under this normalization.
  • A straight line in two features becomes a hyperplane in higher dimensions.
  • Support vectors touch margin boundaries in the separable illustration; the classifier itself lies between boundaries.

For overlapping classes use hinge loss ℓᵢ = max(0, 1 − yᵢf(xᵢ)). A consistent lecture-style objective is Σᵢℓᵢ + λ||w||². Larger λ emphasizes margin / regularization; smaller λ emphasizes fitting training observations. Many packages instead use (1/2)||w||² + CΣᵢℓᵢ: larger software C emphasizes fitting. Do not infer direction from the symbol alone: inspect its location in the objective. Software C is unrelated to CUSUM's C.

Clarification: hinge loss penalizes both misclassification and correct classification inside the margin. If yᵢf(xᵢ)=0.5, the class sign is correct but loss is 0.5. If it equals −0.5, the prediction is wrong and loss is 1.5. If it equals 1.5, loss is zero. It is not simply a count of classification errors.

Different error costs can be reflected by different loss multipliers or by moving the boundary. Move a boundary to protect against the more costly error; this may deliberately increase the cheaper error. No general rule says the symmetric midpoint maximizes real-world value.

Kernel SVM permits nonlinear boundaries; kernel mathematics is outside the lecture scope. Once features are on comparable scales, near-zero linear coefficients can suggest weak contributions, but correlated variables and model context complicate interpreting them as universally irrelevant.

k-NN

For a new observation: compute distances, find k nearest labeled training observations, predict their most frequent class. Multi-class classification follows the same rule; a plurality need not exceed 50%.

Choose k by validation. Feature weights can give important dimensions more influence; removing irrelevant dimensions can improve neighborhoods. Supplement: small k is sensitive to local noise, while large k smooths local distinctions. Odd k avoids a binary vote tie under simple voting, but does not resolve every multi-class or equal-distance tie. A tie policy is still needed.

Scaling / standardization

Min–max scaling: uᵢⱼ = (xᵢⱼ − minⱼ)/(maxⱼ − minⱼ). To map minimum to a and maximum to b, use a + (b−a)uᵢⱼ. Standardization: zᵢⱼ = (xᵢⱼ − μⱼ)/σⱼ.

Scale affects SVM penalties and neighbor/cluster distances. A numerically large feature should not dominate merely because of its units. Centering/scaling also affects which PCA directions explain most variance.

Clarifications: standardization gives mean zero and standard deviation one, not a normally shaped distribution. Min–max bounds apply to the fitted data range; a future point outside that range can transform outside [0,1]. Constant columns need special handling because their range or standard deviation is zero. Fit preprocessing on training data and reuse it on validation/test/new observations. Trees generally do not require scaling because order-based thresholds are preserved by monotone rescaling.

3. Validation and data splitting — Module 3

Training performance is optimistic because fitting captures both real structure and dataset-specific random patterns. A more flexible model can fit more random patterns; excellent training fit is not enough.

Data roleUseWhy another set may be needed
TrainingFit model coefficients, centers, etc.Training score benefits from fitting its own noise
ValidationSelect method/settings among candidatesWinning candidate can benefit from validation-set luck
TestEstimate performance after selectionMust remain independent of fitting and selection

For a single predetermined model, a train/test split can suffice. Comparing models or tuning k, λ, p/d/q, features, or thresholds is model selection and requires validation or cross-validation before final testing.

Lecture examples: 70/30 to 90/10 train/test; 50/25/25, 60/20/20, or 70/15/15 train/validation/test. These are examples, not universal requirements. Enough representative observations in each set matters more than a particular ratio.

Random splitting can accidentally underrepresent periods or subgroups. Rotation gives systematic coverage but can synchronize with a cycle: assigning every fifth point to the same set can segregate weekdays. Stratification within meaningful groups is a possible remedy.

k-fold CV: reserve test data; partition the remaining observations into k folds. Fit on k−1 folds, validate on the other fold, repeat k times, and average validation results for each candidate specification. Every observation is used for validation once and training k−1 times. The lecture notes 10 folds are common. Select the specification, then refit using all non-test observations and evaluate once on the test set. Do not choose one fold's fitted model or average fold coefficients as the default final model.

Supplement for forecasting: validation must reproduce the deployment timeline. Use past observations to predict later observations, with chronological holdouts or rolling/expanding windows. Random or rotating splits can leak future information when forecasting. Likewise, repeated observations from the same entity may need grouped splitting. Refit preprocessing inside each CV training fold.

4. Distance and clustering — Module 4

Minkowski distance dₚ(x,z) = (Σⱼ|xⱼ−zⱼ|ᵖ)^(1/p), with p ≥ 1 for a norm.

NormFormulaInterpretation/example
L1 / ManhattanΣⱼxⱼ−zⱼGrid travel or sequential movements: add required times
L2 / Euclideansqrt(Σⱼ(xⱼ−zⱼ)²)Straight-line distance
L∞maxⱼxⱼ−zⱼSimultaneous independent movements: the slowest determines completion

For coordinate differences 3 and 4, distances are 7, 5, and 4 respectively. Changing the metric or weights can change neighbors and groups.

k-means

  • Choose k and initial centers.
  • Assign every observation to its closest center.
  • Recalculate each center as the mean of its assigned observations.
  • Repeat until assignments stop changing (or the implementation's stopping criterion is met).

For standard Euclidean k-means, the objective is within-cluster sum of squared distances: WSS = ΣₖΣᵢ∈cluster k ||xᵢ−cₖ||². The arithmetic mean minimizes this objective. The lecture verbally describes total “distance”; distinguish that shorthand from an unsquared-distance objective, whose optimal center generally differs.

The method is a heuristic: different initial centers can produce different local solutions. Run multiple starts and compare objective values at the same k. The lecturer describes its alternating steps as an EM-style approach; this does not make it a general probabilistic mixture model.

Increasing k cannot worsen the globally optimal WSS; k equal to the number of distinct observations can give zero WSS. Therefore do not select k merely by taking the smallest raw WSS. Use an elbow (where improvement slows) together with operational needs, such as the budget for four facilities. Individual heuristic runs can look non-monotonic because they stop at different local solutions.

An outlier is still assigned to the nearest center and can pull its mean. Investigate its meaning; automatic removal may discard an important segment. Supplement: standard k-means is best suited to compact Euclidean groups and can struggle with elongated/nonconvex clusters or strongly unequal sizes/densities.

For a new point, keep the learned centers and assign the nearest one. The regions of all points closest to each center form a Voronoi partition. Assigning a very distant new point does not establish that it is substantively similar enough to the cluster.

Three different k's: k-NN counts neighbors; k-means counts clusters; k-fold CV counts folds. Their meanings and tuning consequences differ.

Representation matters: the missing beat can become a point outlier if represented as an unusually long interval between beats.

A boxplot flags candidate one-dimensional outliers. The lecture discusses choosing reasonable whisker limits such as percentiles; plotting conventions vary. Supplement: common Tukey fences use Q1−1.5 IQR and Q3+1.5 IQR, with whiskers ending at observations within those fences. Neither convention proves that flagged observations are errors.

Model residuals can reveal contextual anomalies: fit an appropriate baseline, then inspect large deviations. There is no universally appropriate upfront detector for every multidimensional or contextual anomaly. A misspecified model can also create large residuals.

Investigate origin: sensor failure, transmission error, contamination, transcription mistake, real rare event, or different operating regime. Correct known errors, omit unusable records, or impute if needed; these modules mention imputation but do not teach its full methods.

Real tails occur naturally in large datasets. Rare delivery delays matter when transporting perishable medicine: removing them can create dangerously optimistic estimates. An alternative is a model for rare-event probability plus a separate model for ordinary delivery time. The lecture's restaurant spike was a verified one-time publicity event, removed only after investigating its relevance to normal forecasting.

Clarification: about 4.55% of normal observations lie beyond ±2 standard deviations and about 0.27% beyond ±3—roughly 2,700 per million, rather than treating the lecture's rounded “about 2,000” as an exact count.

6. Change detection and ethics — Module 6

CUSUM detects evidence that the process mean has shifted, distinguishing persistent small deviations from ordinary fluctuation. It is not primarily a forecasting model or a one-point anomaly detector.

Upper CUSUM, initialized S₀⁺=0:

Sₜ⁺ = max(0, Sₜ₋₁⁺ + xₜ − μ − C); signal when Sₜ⁺ > T.

An equivalent positive-valued lower CUSUM:

Sₜ⁻ = max(0, Sₜ₋₁⁻ + μ − xₜ − C); signal when Sₜ⁻ > T.

Run both for two-sided detection. A signed negative lower statistic is another convention; keep the statistic and threshold signs consistent.

  • μ is the unchanged baseline expectation.
  • C discounts small departures: larger C reduces sensitivity.
  • T is accumulated evidence required: larger T generally delays alarms and reduces false alarms.
  • Resetting to zero prevents a long run of deviations in the opposite direction from hiding a later change.
  • A single extreme observation can still trigger an alarm; CUSUM does not require every observation to exceed μ+C.

Trade off wasted production during detection delay against unnecessary maintenance after a false alarm. The lecture's rail-axle example favors quicker warnings because waiting for conventional statistical certainty could be too late. Tune C and T using representative data and actual error costs. A control chart plots the statistic and alarm boundary.

The homework wrap-up emphasizes honest reporting. Different definitions of “summer ends,” preprocessing, settings, and interpretations can yield different answers. Report what the analysis supports rather than forcing a preferred conclusion. Later-ending summers alone cannot establish longer/hotter summers without information about when they start; the provided local dataset cannot settle a much broader question.

7. Time-series models — Module 7

Use ℓₜ for level, bₜ for trend, sₜ for seasonality, and m for cycle length here to avoid collisions with CUSUM symbols.

Single smoothing

ℓₜ = αxₜ + (1−α)ℓₜ₋₁; lecture initialization ℓ₁=x₁.

Smaller α smooths more and responds slowly; larger α responds quickly and follows more noise. At α=1 the estimate equals the latest observation; at α=0 the initialized level never changes. Expanding the recursion gives recent-observation weights α(1−α)ʲ and a remaining weight on the initialized level. The previous level summarizes the entire available history.

Forecast at horizon h: x̂ₜ₊ₕ|ₜ=ℓₜ for all h≥1. A constant point forecast does not imply zero uncertainty; uncertainty generally increases with horizon.

Holt / trend

ℓₜ = αxₜ + (1−α)(ℓₜ₋₁+bₜ₋₁)

bₜ = β(ℓₜ−ℓₜ₋₁) + (1−β)bₜ₋₁

x̂ₜ₊ₕ|ₜ = ℓₜ + h bₜ.

Lecture initialization: b₁=0. β controls how rapidly trend estimates change; it does not have to equal α. Multi-step forecasts accumulate h periods of trend.

Holt–Winters / multiplicative seasonality

ℓₜ = α(xₜ/sₜ₋ₘ) + (1−α)(ℓₜ₋₁+bₜ₋₁)

bₜ = β(ℓₜ−ℓₜ₋₁) + (1−β)bₜ₋₁

sₜ = γ(xₜ/ℓₜ) + (1−γ)sₜ₋ₘ.

One-step forecast: x̂ₜ₊₁|ₜ=(ℓₜ+bₜ)sₜ₊₁₋ₘ. For general h, use (ℓₜ+h bₜ) times the most recently estimated seasonal factor for that future position in the cycle. Recycle the last full seasonal cycle beyond the first horizon cycle.

m is in observation periods: daily observations with weekly seasonality → m=7; hourly observations with daily seasonality → m=24. The lecture sets initial seasonal factors to 1 and initial trend to zero; implementations may estimate better initial states from early cycles. γ controls how rapidly seasonal effects adapt.

Multiplicative s=1.1 means 10% above baseline; 550 observed with s=1.1 corresponds to a deseasonalized 500. Additive seasonality instead represents a fixed unit offset. Multiplicative division is inappropriate at zero and problematic for signed series; it is most natural when seasonal amplitude scales with a positive level.

Tune α, β, γ in [0,1] by minimizing training forecast squared errors, then validate forecasting performance. Compute each forecast before observing its target; a smoothed estimate using xₜ is not an honest forecast of xₜ.

ARIMA

For zₜ = Δᵈxₜ, a conventional representation is:

zₜ = c + Σᵢ₌₁ᵖφᵢzₜ₋ᵢ + εₜ + Σⱼ₌₁ᵠθⱼεₜ₋ⱼ.

Some software uses the opposite sign for MA coefficients. The interpretation is unchanged: p past values and q past innovations of the differenced series.

Δxₜ=xₜ−xₜ₋₁. Δ²xₜ=xₜ−2xₜ₋₁+xₜ₋₂. d=2 means differences of differences, not simply xₜ−xₜ₋₂. Stationarity means stable distributional behavior; for weak stationarity, mean/variance are constant and covariance depends on lag. Differencing can remove certain trends; it does not guarantee stationarity for every series.

SpecificationLecture connection
ARIMA(0,0,0)White noise, allowing an appropriate mean convention
ARIMA(0,1,0)Random walk; drift depends on intercept convention
ARIMA(p,0,0)AR(p)
ARIMA(0,0,q)MA(q)
ARIMA(0,1,1)Related to simple exponential smoothing under compatible conventions/initialization

MA here means lagged errors/innovations, not an arithmetic moving average of observations. AR uses lagged values of the same response rather than unrelated external factors. Seasonal ARIMA extensions are mentioned but not developed. Select orders, fit coefficients, compare validated performance and fit criteria. The lecture's roughly 40-observation guideline is a rule of thumb, not a universal minimum or guarantee. Its preference for ARIMA on steadier data is likewise a heuristic.

GARCH

GARCH predicts conditional variance rather than the expected level. A useful supplemental GARCH(1,1) equation is hₜ=ω+aεₜ₋₁²+b hₜ₋₁. Previous squared shocks and previous variance influence today's variance. Common positivity constraints are ω>0 and a,b≥0; a+b<1 supports a finite unconditional variance in the standard formulation.

General models include multiple variance and squared-shock lags. Order labels p/q differ across conventions; state which counts each kind of lag. There is no ARIMA-style d term. A mean model and GARCH variance model can be combined. The lecture motivates variance as uncertainty and a proxy for investment volatility/risk, not as a complete definition of risk.

8. Regression, likelihood, and output — Module 8

Linear regression and transformations

yᵢ=β₀+Σⱼβⱼxᵢⱼ+εᵢ; fitted ŷᵢ=β̂₀+Σⱼβ̂ⱼxᵢⱼ. Least squares minimizes SSE=Σᵢ(yᵢ−ŷᵢ)². Residuals are differences in response, not perpendicular geometric distances to the fitted line. Squaring emphasizes large residuals. The objective is convex; a unique coefficient solution additionally requires identifiable predictors / full column rank.

For an additive model, βⱼ is the expected response difference per unit of predictor j, holding the other included predictors fixed. The intercept is the prediction when included predictors equal zero; that point may be outside a useful observed range.

Descriptive use emphasizes coefficient meaning; predictive use emphasizes out-of-sample predictions. Associations and good predictions do not establish causes. A third factor may cause both apparent predictor and response. Consider time order, plausible mechanisms, and confounding; randomized controlled comparisons can strengthen causal reasoning.

Adding x², log(x), or x₁x₂ as columns still permits regression linear in coefficients. An interaction means the effect of one predictor depends on another: in y=β₀+β₁x₁+β₂x₂+β₃x₁x₂, the effect of x₁ is β₁+β₃x₂. Thus β₁ alone is the effect at x₂=0. A 0/1 indicator represents a difference relative to a reference category. Transforming the response changes the scale of interpretation and requires appropriate back-transformation for predictions.

Likelihood and information criteria

Likelihood evaluates observed data as a function of model parameters: L(θ)=p(data | θ), using densities for continuous observations. It is not p(θ | data). Under independent, identically distributed normal errors with common variance, maximizing likelihood for regression coefficients is equivalent to minimizing SSE.

Let ℓ*=log L* and K denote the number of estimated parameters:

  • AIC = −2ℓ* + 2K.
  • AICc = AIC + 2K(K+1)/(n−K−1), requiring n>K+1.
  • BIC = −2ℓ* + K log(n).

Lower values are preferred on comparable data and likelihood definitions. Higher likelihood alone rewards extra flexibility; the penalty discourages fitting noise. BIC has a larger per-parameter penalty than AIC when log(n)>2. AICc adds a finite-sample correction and approaches AIC as n grows for fixed K.

The lecture counts regression coefficients as m+1. Clarification: when estimating residual variance through likelihood, software may also count that parameter; use consistent definitions. Comparisons involving transformed responses require care about likelihood scale/Jacobian and are not automatically comparable as raw software numbers.

AIC relative support for model i versus the lowest-AIC candidate is exp(−ΔAICᵢ/2). A difference of 5 gives exp(−2.5)≈0.082. The transcript's exponent wording is corrupted; the worked example identifies the intended half-difference formula. Relative support is not a guarantee of truth. Lecture BIC heuristics: differences 0–2 slight, 2–6 moderate, 6–10 stronger, ≥10 very strong preference for the lower score. These criteria do not replace held-out performance checks.

Regression output

  • Coefficient and standard error describe estimated magnitude and uncertainty.
  • t-statistic for a zero null: estimate / standard error.
  • Confidence interval shows uncertainty; exclusion of zero corresponds to a two-sided significance test at the matching level under matching assumptions.
  • R²=1−SSE/SST, with SST=Σᵢ(yᵢ−ȳ)², in ordinary intercept-based regression.
  • Adjusted R²=1−[SSE/(n−m−1)]/[SST/(n−1)], for m predictors excluding intercept.

Adding predictors cannot decrease ordinary training R² in a nested least-squares model. Adjusted R² can decrease. Neither metric proves good future prediction; test R² can be negative. An R² of 0.59 describes 59% of sample response variation accounted for relative to the mean baseline, not 59% correct classifications or 59% causal explanation. Context matters: noisy behavioral systems can have useful models with moderate R².

Important correction to the transcript: a p-value is the probability, assuming the null hypothesis and model assumptions, of a test statistic at least as extreme as observed. It is not the probability that a coefficient is zero. A p-value of .02 does not mean a 2% probability that this predictor is irrelevant. Nor do 100 such observed p-values imply exactly two irrelevant predictors. Multiple testing raises false-positive concerns, but that particular reasoning is invalid. Statistical significance also does not measure practical effect size. ASA statement.

The lecture suggests .05 as a common selection threshold; treat it as a heuristic rather than automatic deletion. Higher thresholds retain more variables; lower thresholds can miss useful ones. Very large samples can reveal tiny effects, but do not automatically make unrelated predictors significant. Domain relevance, coefficient magnitude, uncertainty, correlated predictors, and validation all matter.

9. Box–Cox, detrending, and PCA — Module 9

Box–Cox

For y>0: gλ(y)=(y^λ−1)/λ if λ≠0; g₀(y)=log(y). λ=1 is y−1; λ=0.5 gives a shifted/scaled square-root transformation. It is a power family, not always logarithmic. Choose λ through an appropriate likelihood or diagnostic criterion. Check model residual behavior and functional form after transforming; do not assume the method always fixes the problem. NIST definition.

The lecture motivates the method through skewness and unequal variability. Clarification: ordinary regression's normality assumption for classical inference concerns errors conditional on predictors, not a requirement that raw response values have a normal histogram. Heteroscedasticity means conditional error variance changes; skewness of a raw histogram alone does not establish it. Heteroscedasticity does not by itself bias OLS coefficients under exogeneity, though conventional standard errors and efficiency can suffer. Transformation may improve fit and variance behavior; inspect residual diagnostics. NIST transformation example.

Detrending

Fit a trend g(t), then define residual series rₜ=xₜ−ĝ(t). A common fit is intercept plus linear time; more appropriate nonlinear forms are possible. Known inflation adjustments can be better than assuming a constant linear trend. Consider predictors as well as responses when time trends distort a factor-based relationship.

Detrending subtracts a fitted systematic component; differencing compares consecutive values. They are distinct operations. Removing a trend need not remove seasonality or produce stationarity. Supplement: fit the trend using the allowed training interval; to recover predictions on the original response scale, add back the estimated future trend (or reverse the particular adjustment used).

PCA

Start with centered X, optionally standardized according to feature scales. Find orthonormal eigenvectors vₖ of XᵀX, ordered by descending eigenvalue λₖ. Let V contain them as columns; component scores are T=XV. Score tᵢₖ=Σⱼxᵢⱼvⱼₖ. Retain the first r columns for dimension reduction.

An eigenvector is a nonzero vector satisfying Av=λv; eigenvalues satisfy det(A−λI)=0. Eigenvectors of this symmetric matrix can be chosen orthogonal. Negative eigenvalues in general matrices can reverse a vector's direction; XᵀX specifically has nonnegative eigenvalues. Component variance is proportional to its eigenvalue; explained predictor-variance fraction is λₖ/Σⱼλⱼ.

  • Keeping every component changes coordinates without discarding information; reducing components loses information.
  • Components are uncorrelated in the fitted sample; uncorrelated is not generally independent.
  • PCA uses only X, not y. High predictor variance does not guarantee response relevance.
  • A low-variance direction can perfectly separate classes while a high-variance one cannot; Module 9's contrasting examples make this explicit.
  • Comparable random-noise levels can make large-variance components have better signal-to-noise ratios, but this is conditional intuition, not a guarantee.
  • Feature extraction creates combinations; feature selection retains original variables.

For regression on components, ŷ=b₀+Tb and implied coefficients in centered/scaled coordinates are a=Vᵣb. If xⱼ was standardized using μⱼ,σⱼ, then original-unit slopes are aⱼ/σⱼ and original intercept is b₀−Σⱼaⱼμⱼ/σⱼ. Merely multiplying loadings and coefficients without reversing preprocessing misses this adjustment. Use training means/scales/loadings for new observations; do not recompute a new PCA independently for test data.

Kernel PCA is mentioned as a nonlinear extension; the simple linear back-transformation formula is for ordinary linear PCA.

10. Trees, forests, logistic regression, and evaluation — Module 10

CART and pruning

Trees recursively split features into regions. A path identifies which leaf predicts a new observation. Ordinary regression trees use the leaf's training response mean. Classification trees use its majority class; a binary-event probability can be estimated by its response fraction. The lecture also describes richer model trees with separate regressions in leaves; these are distinct from ordinary constant-leaf CART.

The lecture's illustrative growing method chooses single-feature splits that sufficiently reduce response variability, subject to a minimum improvement Δ and adequate child sample sizes. Clarification: for squared-error regression, compare child SSE or appropriately size-weighted variances; simply adding two unweighted variances need not reflect the total fit improvement.

The example grows on half the available fitting data and prunes using the other half, removing splits that do not improve evaluation error. That pruning subset has a validation role; a final test set remains separate. The 5%-of-data leaf-size guideline is a lecture heuristic, not a defining CART requirement. Depth, minimum leaf size, improvement thresholds, and pruning constrain overfitting. Splitting down to one observation per leaf may memorize training data.

Trees capture threshold effects, nonlinear patterns, and interactions through different paths. A small tree can be easy to explain; many complicated paths or leaf-specific regression models can be difficult. A low-quality leaf can point to a segment needing more informative predictors.

Random forests

For each tree, draw n observations with replacement from n training observations; duplicates and omitted points are expected. At each split, draw a random subset of predictor candidates and choose a useful split within it. These two sources of randomness diversify trees; a forest is not just repeated identical trees on unchanged data.

Regression aggregates by averaging; classification aggregates by most common class (or averages class probabilities in implementations using that representation). Trees are generally grown without ordinary post-pruning in the lecture approach. They still have splitting/size controls. Averaging can reduce individual trees' overreaction to noise, especially when their errors are not highly correlated.

The lecture mentions hundreds of trees, often 500–1,000+, and roughly 1+log(number of predictors) candidates per split. These are illustrative choices; validate settings and do not confuse number of observations with number of predictors. Variable importance summarizes contribution, not a simple signed coefficient or causal effect. Prediction can be strong while the aggregate reasoning is hard to explain. More trees do not compensate for data leakage or unsuitable data.

Logistic regression and ROC

η=β₀+Σⱼβⱼxⱼ; p=P(Y=1|x)=1/(1+exp(−η)). Observed responses are 0/1; fitted probabilities lie between 0 and 1 for finite η. As η→−∞, p→0; as η→+∞, p→1. This prevents impossible probabilities from an unconstrained linear response model.

Supplement: log(p/(1−p))=η. A one-unit predictor increase multiplies odds by exp(βⱼ), holding others fixed and with no relevant interaction. It does not increase probability by βⱼ points. Maximum likelihood typically uses iterative computation rather than a least-squares closed form.

Transformations/interactions and tree-based variants are possible. Pseudo-R² measures differ and do not have ordinary R²'s “fraction of response variance explained” interpretation.

To classify, choose positive when p≥τ. Raising τ usually decreases both true-positive and false-positive rates; lowering it increases both. Which direction is desirable depends on which outcome is labeled positive and the costs. A threshold of .5 is not inherently optimal.

ROC plots sensitivity against 1−specificity across thresholds. AUC measures ranking: probability a random positive receives a higher score than a random negative, counting score ties by half in the standard convention. AUC=.5 corresponds to chance ranking; 1 is perfect ranking. AUC is not accuracy at a particular threshold, calibration of probability estimates, or expected economic value.

Value / costs

Total cost = cTP·TP + cFN·FN + cFP·FP + cTN·TN. Divide by N for average cost. If correct decisions cost zero, missing a real message costs $1, and passing spam costs $.04, the example costs $14/1,000=$.014 per incoming message.

If real mail prevalence is 60%, holding class-conditional performance fixed gives expected counts TP=588,FN=12,FP=80,TN=320 per 1,000; cost=$15.20 or $.0152 per message. This rescaling assumes performance within each class remains stable; arbitrary population changes may violate that assumption.

More generally with positive prevalence π, sensitivity Se and specificity Sp:

Expected cost = π[Se·cTP+(1−Se)·cFN]+(1−π)[(1−Sp)·cFP+Sp·cTN].

Supplement: with calibrated probabilities and zero cost for correct decisions, predict positive if p≥cFP/(cFP+cFN). This follows by comparing expected positive-decision cost (1−p)cFP with negative-decision cost p cFN. The lecture's stricter spam filter has higher accuracy but worse value because missing real messages is expensive. Evaluate the objective the decision actually serves.

Advanced regression: awareness level in the lecture

Poisson regression models a nonnegative count using a conditional Poisson mean λ(x). Supplement: a common link is log λ(x)=β₀+Σⱼβⱼxⱼ; Poisson variance equals its mean conditionally. Exposure length matters for rates, and overdispersion can make a simple Poisson assumption inadequate. The lecture does not derive these details.

Splines fit polynomial pieces joined at knots; degree/order and knot placement determine flexibility. Appropriate smoothness prevents arbitrary jumps at nearby predictor values. MARS stands for multivariate adaptive regression splines; the transcript's “multi-adaptive” wording is incomplete. The lecture mentions the alternative name Earth but does not teach the implementation.

Bayesian regression combines a prior distribution over coefficients/error behavior with a likelihood: posterior ∝ likelihood × prior. Its output reflects updated uncertainty. Informative expertise can help with small samples; misleading priors can also pull results in the wrong direction. Weak/broad priors leave more influence to data. Priors are distributions over unknowns, not fabricated extra observations.

k-NN regression averages neighbors' numeric responses; k-NN classification votes on labels. Both depend on metric, scaling, relevant dimensions, and k. Neither requires specifying a global linear equation.

Final review prompts

Before choosing or interpreting any model, answer:

  • Is the task descriptive, predictive, or a decision requiring costs/constraints?
  • Is the response known? Is it a class, probability, numeric amount, count, or variance?
  • Is data ordered in time, and can the evaluation accidentally use future information?
  • Which settings are tuned versus learned? What happens when each setting increases?
  • Does the method depend on distance, scale, separability, stationarity, or conditional-error assumptions?
  • What objective is optimized: hinge loss, WSS, SSE, likelihood, variance reduction, or decision cost?
  • What would cause overfitting, and which independent data estimates final performance?
  • Does an output describe association, predictor variance, uncertainty, ranking, or actual value?
  • Are outliers/errors/rare regimes handled in a way that matches the intended use?
  • Can the result be explained enough for the decision, and does the conclusion faithfully reflect the evidence?

High-priority distinctions: margin versus classification error; λ versus software C; standardization versus normality; nearest-neighbor voting versus centroid assignment; training versus validation versus test; differencing versus detrending; AR/MA versus GARCH; additive versus multiplicative seasonality; high training R² versus future accuracy; p-value versus effect size; PCA predictor variance versus response relevance; leaf means versus leaf regressions; tree versus forest; sensitivity versus precision; AUC versus calibration; accuracy versus expected cost.

A repeatable way to solve scenario questions

  • Identify the response. Is it an unknown group, known class, event probability, numerical level, count, conditional variance, or evidence of a shift?
  • Identify the available information. Are labels known? Are the observations independent or ordered? Which predictors exist before the decision?
  • Choose the method family that answers that precise question. A probability forecast, a class decision, a detected change, and an action are different outputs.
  • Identify settings and assumptions: units, scaling, cycle length, stationarity, similarity geometry, flexibility, and initial conditions.
  • Evaluate on independent information. Separate fitting, selection, and final testing, including all preprocessing and thresholds.
  • Interpret the response's direction and scale. Higher failure probability is worse, but higher operating hours before failure is better. A positive trend's meaning depends on the response.
  • Check whether the answer claims causation without design support, treats fit as generalization, or treats a convenient rule of thumb as a universal law.

For multi-select, evaluate each statement independently. A true statement can still be an incorrect answer if it does not support the conclusion requested. For example, “the tree has fewer training errors” may be factually true while failing to establish that the tree is better because its tiny leaves fit noise.

Book-supported refinements that prevent common mistakes

Bias, variance, and irreducible error

For squared-error prediction at an input, expected error can be expressed as squared bias plus estimation variance plus irreducible noise under the usual regression formulation. Bias is systematic mismatch between an average fitted prediction and the true conditional relationship; variance is how fitted predictions change across different training samples. A very restrictive model may miss curvature (high bias), while a very flexible model may follow accidental sample patterns (high variance).

Training error typically decreases as model flexibility increases. Test error often initially decreases and then rises as fitting noise outweighs gains in capturing real structure. This is a useful sketch, not a requirement that every empirical validation curve form a smooth U. No method is best for every dataset.

Parameter direction matters: increasing k in neighbor methods generally smooths predictions; increasing polynomial degree or tree depth generally increases flexibility; increasing a norm-penalty coefficient discourages large coefficients. For SVM, the direction of a symbol called C depends on the formulation.

The book's budget C and common software's loss-penalty C move in different directions. Always identify the exact objective or constraint. Soft classification can also be sensible even when perfect separation is technically possible if strict separation is excessively sensitive to one unusual point. In soft-margin solutions, support can include observations on or inside margins and misclassified observations; the lecture's “boundary-touching points” picture is the simplest separable case.

Residual outliers, leverage, and influence

A regression residual outlier has an unusual response given the fitted relationship. A high-leverage observation has an unusual predictor configuration relative to the feature cloud. An influential observation materially changes a fitted model when included versus removed. These are different ideas: a high-leverage point can have a small residual if it lies near the fitted relationship, and a large-residual point with ordinary predictor values need not drastically change the slope. High leverage combined with a large residual deserves particular attention.

Do not rely solely on one-variable boxplots: a combination can be unusual even when each separate feature value is ordinary. Likewise, do not interpret an extreme residual as definitive bad data. It can indicate missing structure or a genuine regime. The operational target decides whether the model should represent it.

Collinearity and conditional interpretation

Correlated predictors can carry overlapping information. A coefficient in a multiple regression describes a predictor's contribution holding the other included predictors fixed; this can differ in sign from its coefficient in a one-predictor regression. That difference is not automatically a software error: marginal and conditional associations ask different questions.

Near collinearity can increase standard errors and make individual slope estimates unstable while predictions within the familiar data region remain useful. Exact linear redundancy prevents uniquely identifying all unconstrained coefficients. PCA creates uncorrelated combinations, but omitting components can still remove outcome-relevant information. Coefficient interpretation, prediction, and response relevance must be considered separately.

Mean-response confidence versus individual prediction intervals

A confidence interval for the conditional mean reflects uncertainty in the estimated average response at a specified feature configuration. A prediction interval for a new individual response also includes that new observation's noise, so it is generally wider at the same nominal coverage. Uncertainty can increase when extrapolating far from training data.

A frequentist 95% interval procedure captures the fixed parameter in about 95% of repeated samples under its assumptions. It is not automatically a posterior 95% probability for the unknown parameter after this particular interval has been observed. Bayesian credible intervals have a different interpretation based on a posterior distribution.

Bagging, random forests, and OOB evaluation

Bagging fits models on bootstrap samples and aggregates their predictions. A random forest adds random candidate-feature subsets at splits to reduce correlated tree behavior. Using all features as candidates at every split returns the ordinary bagging comparison in the book's tree framework.

An observation is out of bag for a tree if that tree's bootstrap sample omitted it. Its OOB prediction aggregates only trees that did not train on that observation. Across n replacement draws from n records, omission probability is (1−1/n)^n, approaching exp(−1), about 36.8%. The sample has n draws but generally fewer than n distinct records. OOB evaluation is useful, but using OOB results repeatedly for selection still motivates a separate final test for a clean evaluation of the selected procedure.

The lectures mention a candidate-feature heuristic near 1+log(number of predictors), while the book illustrates roughly sqrt(number of predictors). These are tuning conventions, not competing definitions of random forests. Select an appropriate setting for the task and implementation. Also distinguish complexity in a single tree from the number of trees in an otherwise fixed forest: adding trees primarily stabilizes the ensemble average; it is not identical to adding depth.

Classification impurity

For class proportions p_k at a node, Gini impurity is sum p_k(1−p_k)=1−sum p_k squared; entropy is −sum p_k log(p_k), with the zero-probability contribution defined by its limit as zero. Both approach zero at purity. For balanced binary proportions, Gini=.5. For proportions .8,.2, Gini=.32. A classification tree ordinarily splits to reduce an appropriately size-weighted impurity.

A regression tree instead reduces squared response error, and the best constant prediction is a mean. Numeric arbitrary class codes are not a universal regression target for a classification tree. These details reinforce the leaf means versus class votes distinction.

Worked mini-cases

1. Unit and outcome interpretation

A batch has 96 instruments, takes between four and six days, and each observation records the number of hours an instrument survives before its first repair. The question asks whether survival differs by sequence position in each batch. Here the observation index advances by instrument, the response is operating hours, and seasonal cycle length is 96 instruments. The average five-day duration is irrelevant to that particular index.

An early-position multiplicative seasonal factor .75 represents 25% lower modeled operating hours relative to adjusted baseline. It does not mean a 25% higher failure probability, and does not prove workers caused it. A positive trend represents increasing operating hours across successive observations, which is improved modeled longevity. If the response were instead failure probability, positive trend would have a different practical implication.

2. SVM loss and margin

Take a normalized signed margin y*f=.25. The class sign is right, but loss=max(0,1−.25)=.75 because it lies inside the correct margin. At y*f=−.25, the sign is wrong and loss=1.25. At y*f=1.25, loss=0.

For w=(6,8), norm(w)=10 and the full margin between f=−1 and f=1 is .2. Multiplying the coefficients without retaining the normalized boundary constraints changes the geometry interpretation; do not treat an arbitrary score scale as a margin normalization.

3. A complete validation pipeline

From 2,000 eligible independent records, reserve 400 for final testing. Use five-fold CV on 1,600: each candidate fit trains on 1,280 and validates on 320. Within each training fold, fit scaling, PCA if used, and all supervised feature selection. Compare average validation decision cost if cost is the deployment objective.

Once the specification, threshold, and preprocessing policy are chosen, refit the pipeline on the 1,600 non-test records and evaluate once on the 400 test records. Do not average the fold coefficients, recompute an independent test PCA, or change the threshold after seeing test errors and still call that score untouched testing.

4. CUSUM accumulation

Upper CUSUM with mu=10, allowance C=1, threshold T=4, initial S=0 receives 12,11,8,14,13. Updates are 1,1,0,3,5. The third observation resets accumulated evidence; the last observation crosses the stated strict threshold. One observation above baseline does not automatically imply an alarm. Increasing C or T would generally make alarms more conservative.

5. A full Holt–Winters update

Use alpha=.4,beta=.2,gamma=.3, previous level=100, previous trend=2, previous same-phase seasonal factor=1.1, current observation=121.

  • Deseasonalized observation=121/1.1=110.
  • Updated level=.4*110+.6*(100+2)=105.2.
  • Updated trend=.2*(105.2−100)+.8*2=2.64.
  • Updated seasonal factor=.3*(121/105.2)+.7*1.1≈1.1151.
  • If the next phase's latest seasonal factor is .9, the one-step forecast=(105.2+2.64)*.9=97.056.

Use the updated factor for its own phase when that phase next recurs, not automatically for the next observation. Keep parameter names separate from the estimated time-varying components.

6. PCA variance and supervised usefulness

Eigenvalues 9,2,1 give first-component predictor-variance fraction .75 and first-two fraction 11/12. These fractions measure X variation. A response can depend mostly on the last component, so 91.7% retained X variance does not promise 91.7% response accuracy.

If a two-feature standardized component has loadings (.6,.8) and its response regression slope is 5, implied standardized-feature slopes are (3,4). With feature standard deviations 2 and 10, raw-unit slopes become (1.5,.4). Restoring the intercept also requires the training feature means.

7. Accuracy, prevalence, and cost

Positive is “requires maintenance.” Suppose TP=30,FN=10,FP=20,TN=140. Sensitivity=.75,specificity=.875,precision=.60,accuracy=.85. If missing a maintenance need costs $100 and unnecessary maintenance costs $5, total error cost=$1,100 across 200 cases, or $5.50 each.

At a new positive prevalence .1, with those class-conditional rates assumed unchanged, expected counts per 1,000 are TP=75,FN=25,FP=112.5,TN=787.5. Expected cost is $3,062.50, or $3.0625 each. Fractional counts are expected counts, not literal possible counts for a realized batch. Precision becomes 75/187.5=.4. The same sensitivity/specificity can therefore yield a different positive-prediction reliability and a different economic outcome.
